# Документация проекта "Бизнес СУБД"

## Общее описание

**Название проекта:** СУБД ого магазина  
**Технологический стек:** C# (.NET) бэкенд + Python Qt6 фронтенд + PostgreSQL  
**Версия:** 1.0.0  
**Статус:** В разработке

### Основные функции системы:
- Управление каталогом цветов и растений
- Складской учет и инвентаризация
- Управление клиентской базой
- Обработка заказов
- Аналитика и отчетность
- Управление персоналом
- Аудит изменений и безопасность

## Функциональные требования

### 1. Управление товарами
- **Каталог товаров:** Добавление, редактирование, удаление товаров и услуг
- **Категории:** Иерархическая структура категорий товаров
- **Атрибуты:** Характеристики, срок годности, цена
- **Изображения:** Загрузка и хранение фотографий товаров

### 2. Складской учет
- **Поступление:** Учет поставок от поставщиков
- **Инвентаризация:** Регулярная проверка остатков
- **Сроки годности:** Контроль просрочки продукции
- **Условия хранения:** Температура, влажность

### 3. Управление заказами
- **Создание заказов:** Формирование заказов от клиентов
- **Статусы:** Отслеживание статусов выполнения
- **Расчет стоимости:** Автоматический расчет с учетом скидок
- **Доставка:** Управление процессом доставки

### 4. Клиентская база
- **Регистрация клиентов:** Ввод контактной информации
- **История заказов:** Просмотр предыдущих заказов
- **Скидки и бонусы:** Система лояльности

### 5. Персонал и права доступа
- **Управление сотрудниками:** Добавление, редактирование
- **Роли и права:** Разграничение доступа по ролям
- **Аудит действий:** Логирование всех операций

## Технические требования

### Бэкенд (C# .NET)
- **Фреймворк:** .NET 8.0
- **Архитектура:** Clean Architecture (Domain, Application, Infrastructure)
- **ORM:** Entity Framework Core
- **База данных:** PostgreSQL
- **API:** RESTful API с OpenAPI/Swagger документацией
- **Аутентификация:** JWT токены
- **Валидация:** FluentValidation
- **Логирование:** Serilog
- **Тестирование:** xUnit, Moq

### Фронтенд (Python Qt6)
- **Фреймворк:** PyQt6
- **Архитектура:** MVC/MVP
- **HTTP клиент:** requests
- **JSON обработка:** json
- **Тестирование:** pytest

### База данных
- **СУБД:** PostgreSQL 15+
- **Миграции:** Entity Framework Migrations
- **Резервное копирование:** pg_dump
- **Оптимизация:** Индексы, запросы
